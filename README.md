# Student Leave Management System (MERN Stack)

## Project Overview
A simple college mini-project for managing student leave applications.
- **Frontend**: React.js (Vite)
- **Backend**: Node.js + Express
- **Database**: MongoDB

## How to Run

### 1. Backend (Server)
```bash
cd server
npm install
npm run dev
```
Server runs on: `http://localhost:5000`

### 2. Frontend (Client)
```bash
cd client
npm install
npm run dev
```
Client runs on: `http://localhost:5173` (default Vite port)

## Folder Structure
- `server/`: Backend API code
- `client/`: Frontend React Application
